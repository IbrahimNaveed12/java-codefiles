# Login Check

## Problem Title & Summary
Check whether the username and password match the expected values and print a success message if they do.

## Logic & Approach
The program stores a username and password, then checks them using nested `if` statements. If both match, it prints `Login successful.`

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
No input required

Login successful.
```
