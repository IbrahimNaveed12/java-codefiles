# Name and Age

## Problem Title & Summary
Read a user’s name and age, then print both values in a single sentence.

## Logic & Approach
The program reads a string for the name and an integer for the age, then concatenates them into a formatted output sentence to display the result.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
ENTER NAME & AGE
Ali
20

Your name is Ali and your age is 20
```
