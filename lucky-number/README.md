# Lucky Number

## Problem Title & Summary
Check whether a four-digit number is lucky by comparing sums of its digits.

## Logic & Approach
The program separates the number into its digits and calculates the sum of the last two digits and the first two digits. If both sums are equal, the number is lucky; otherwise it is not.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter a four-digit number
1234

THE ENTERED NUMBER IS NOT LUCKY NUMBER
```
