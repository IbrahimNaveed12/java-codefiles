# Right-Sided Triangle

## Problem Title & Summary
Print a five-row, right-aligned inverted triangle using asterisks.

## Logic & Approach
The outer loop controls the rows. Each row prints an increasing number of leading spaces followed by a decreasing number of asterisks.

## Time & Space Complexity
Time Complexity: O(n^2)
Space Complexity: O(1)

## Example Input & Output
```text
 *****
  ****
   ***
    **
     *
```
