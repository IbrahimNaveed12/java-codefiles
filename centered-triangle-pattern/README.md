# Centered Triangle Pattern

## Problem Title & Summary
Print a five-row centered triangle using asterisks.

## Logic & Approach
The outer loop controls the rows. Each row prints fewer leading spaces and an odd number of asterisks, increasing from one to nine.

## Time & Space Complexity
Time Complexity: O(n^2)
Space Complexity: O(1)

## Example Input & Output
```text
     *
    ***
   *****
  *******
 *********
```
