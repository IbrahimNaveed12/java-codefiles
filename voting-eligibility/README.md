# Voting Eligibility

## Problem Title & Summary
Read a person's age and determine whether they are eligible to vote based on the minimum age requirement.

## Logic & Approach
The program reads the age and checks whether it is 18 or above. If the age qualifies and the user is considered a citizen, it prints `Eligible to vote`.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter Age
20

Eligible to vote
```
