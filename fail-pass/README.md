# Fail or Pass

## Problem Title & Summary
Read a student's marks and print whether they passed or failed.

## Logic & Approach
The program reads an integer mark and checks whether it is at least 50. If the score is 50 or higher, it prints `pass`; otherwise it prints `fail`.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter marks
75

75
pass
```
