# Pizza Order

## Problem Title & Summary
Check whether a pizza has been ordered and, if so, determine its size and price.

## Logic & Approach
The program reads the order status first. If the user ordered a pizza, it reads the size and uses an else-if ladder to select the matching price. If the order status is not 1, it prints that no pizza was ordered.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Press to order pizza (1 = Pizza, 0 = No Pizza) :
1
Size (1 = Small, 2 = Medium, 3 = Large):
2

Medium Pizza price is 800RS
```
