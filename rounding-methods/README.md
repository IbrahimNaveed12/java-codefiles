# Rounding Methods

## Problem Title & Summary
Display the results of Java's `Math.rint` and `Math.round` methods.

## Logic & Approach
The program passes `3.5` to `Math.rint` and `1.5` to `Math.round`, then prints both results on one line.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
4.0 2
```
