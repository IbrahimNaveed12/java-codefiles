# Calculator

## Problem Title & Summary
Read two numbers and an operation choice, then display the result of the selected arithmetic calculation.

## Logic & Approach
The program collects two numeric values and an integer representing the operation. It uses a chained `if`/`else if` structure to choose between addition, subtraction, multiplication, and division, then prints the final result.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter any two numbers
20 5
Enter 1 for Addition, 2 for subtration , 3 for multiplication , 4 for division of two numbers
3

YOUR RESULT IS :100
```
