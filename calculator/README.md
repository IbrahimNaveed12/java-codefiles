# Calculator

## Problem Summary
Read two numbers and perform addition, subtraction, multiplication, or division.

## Logic
The program reads both numbers and an operation choice from the user, then prints the result.

## Example
```text
Enter any two numbers
8
2
Enter 1 for Addition, 2 for subtraction, 3 for multiplication, 4 for division of two numbers
1
YOUR RESULT IS :10.0
```

Compile and run with `javac Calculator.java` and `java Calculator`.
