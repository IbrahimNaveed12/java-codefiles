# Weather Travel Check

## Problem Title & Summary
Decide travel advice based on temperature and rain conditions.

## Logic & Approach
If the temperature is below 10°C, the program asks whether it is raining. Depending on that answer, it prints either "Take a taxi" or "Wear warm clothes"; otherwise, it prints that the travel conditions are normal.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter Temperature :
8
If its raining press 1 else press 0 :
1

Take a taxi
```
