# Loop Exercises - Meet

## Problem Title & Summary
This folder includes short loop-based practice exercises for printing patterns and checking loop behavior.

## Logic & Approach
The programs use nested loops and basic arithmetic logic to generate output such as a star pattern and simple sequential text printing.

## Time & Space Complexity
Most examples run in O(n^2) for nested loops and O(1) for single-loop tasks.

## Example Outputs
```text
*
**
***
****
```
