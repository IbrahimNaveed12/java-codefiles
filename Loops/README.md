# Java Loops Practice

## Problem Title & Summary
This folder contains several beginner Java programs focused on loops, iteration, and control flow.

## Logic & Approach
Each file demonstrates a different loop pattern such as `for`, `while`, and `do-while` to solve simple programming exercises.

## Time & Space Complexity
The complexity varies by exercise, but most programs run in linear time based on the input or range being processed.

## Example Programs
- even numbers in ascending order
- even numbers in descending order
- reading a valid number between 1 and 10
- counting non-zero numbers with do-while
