# Cafe

## Problem Summary
Manage three cafe orders, including bill updates, discounts, sales analysis, customer searches, and food-item counts.

## Logic
The program collects customer orders, keeps a backup of the original bills, updates a bill, applies discounts to bills over 500, calculates revenue and the average and highest bill, then searches for a customer and counts orders for a selected food item.

## Run
Compile and run with `javac Cafe.java` and `java Cafe`.
