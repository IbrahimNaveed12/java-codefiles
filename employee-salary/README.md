# Employee Salary

## Problem Title & Summary
Compute the gross salary by adding an employee’s basic salary and house allowance.

## Logic & Approach
The program reads the employee name, basic salary, and house allowance, adds the values together, and prints the gross salary result.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
----- Employee Salary -----
Employee Name: Ahmed
Basic Salary: 60000
House Allowance: 15000

Gross Salary: 75000.0
```
