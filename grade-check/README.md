# Grade Checker

## Problem Title & Summary
Read a student's marks and print the grade based on the score range.

## Logic & Approach
The program checks the marks against multiple ranges using `if` and `else if` conditions. Each range maps to a grade from A to F.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter Marks
85

A
```
