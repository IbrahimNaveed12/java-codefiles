# Read Number Between 1 and 10

## Problem Title & Summary
Read an integer from the user and keep asking until the value is between 1 and 10.

## Logic & Approach
The program uses a `while` loop to validate user input. If the number is outside the accepted range, it prompts again until the input is valid.

## Time & Space Complexity
Time Complexity: O(n)
Space Complexity: O(1)

## Example Input & Output
```text
Enter a number between 1 and 10: 15
15 is not between 1 and 10. Try again: 7
7 is between 1 and 10. Thanks!
```
