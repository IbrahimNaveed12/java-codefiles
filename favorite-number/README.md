# Favorite Number

## Problem Title & Summary
Read a favorite number and print it back with a friendly message.

## Logic & Approach
The program reads an integer from the user and prints it with a sentence confirming it is also the program author’s favorite number.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter your favourite number
7

7, is also my favourite number
```
