# Restaurant Menu

Add selected items to a restaurant bill and let the user order multiple items.

The program displays prices for burgers, pizza, and sandwiches, adds valid selections to the running total, and repeats while the user answers `y`.

## Example
```text
--- Restaurant Menu ---
1. Burger   - Rs. 500
2. Pizza    - Rs. 1,200
3. Sandwich - Rs. 350
Select an item (1-3): 1
Burger added.
Do you want to order another item? (y/n): n

Total Bill: Rs. 500
```

Compile and run with `javac RestaurantMenu.java` and `java RestaurantMenu`.
