# Even Numbers from 100 to 2

## Problem Title & Summary
Print all even numbers from 100 down to 2 in descending order.

## Logic & Approach
The loop starts at 100 and decrements until 1. Each value is checked with `% 2 == 0`; if it is even, the program prints it.

## Time & Space Complexity
Time Complexity: O(n)
Space Complexity: O(1)

## Example Input & Output
```text
100 98 96 94 ... 2
```
