# Sequence Print

## Problem Title & Summary
Print a short sequence of letters in one line with line breaks between groups.

## Logic & Approach
The program uses sequential `System.out.print` and `System.out.println` statements to output the required characters in the desired order.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
ABCD
E
```
