# Even Numbers from 1 to 100

## Problem Title & Summary
Print all even numbers from 1 to 100 in ascending order.

## Logic & Approach
The program loops from 1 to 100 and checks each number using `% 2 == 0`. If the number is even, it prints it.

## Time & Space Complexity
Time Complexity: O(n)
Space Complexity: O(1)

## Example Input & Output
```text
2 4 6 8 10 ... 100
```
