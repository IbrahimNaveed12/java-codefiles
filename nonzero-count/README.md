# Count Non-Zero Numbers

## Problem Title & Summary
Read integers until the user enters 0, then count how many non-zero values were entered.

## Logic & Approach
The program uses a `do-while` loop. It reads each value, increments the counter when the number is not zero, and stops when 0 is entered.

## Time & Space Complexity
Time Complexity: O(n)
Space Complexity: O(1)

## Example Input & Output
```text
Enter integers [to stop enter 0]
3
5
8
0
Nonzero integers entered: 3
```
