# Count Non-Zero Numbers with a For Loop

Read integers until the user enters `0`, then report how many non-zero numbers were entered.

The program uses a `for` loop to read each value and increments the count only for non-zero values.

## Example
```text
Enter integers [to stop enter 0]
3
Enter integers [to stop enter 0]
5
Enter integers [to stop enter 0]
0
Nonzero integers entered: 2
```

Compile and run with `javac NonzeroCounterForLoop.java` and `java NonzeroCounterForLoop`.
