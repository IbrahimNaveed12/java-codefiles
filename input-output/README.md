# Read and Print Three Integers

## Problem Title & Summary
Read three integers from user input and print each one on a new line.

## Logic & Approach
The program reads three values from standard input and prints each value separately using `println` statements.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
10
20
30

10
20
30
```
