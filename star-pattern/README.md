# Star Pattern

## Problem Title & Summary
Print a triangular star pattern with rows increasing from 1 to 4.

## Logic & Approach
The program uses nested loops: the outer loop controls the row number, and the inner loop prints stars for each row.

## Time & Space Complexity
Time Complexity: O(n^2)
Space Complexity: O(1)

## Example Input & Output
```text
*
**
***
****
```
