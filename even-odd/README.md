# Even or Odd

## Problem Title & Summary
Determine whether a number is even or odd.

## Logic & Approach
The program reads an integer and checks the remainder when it is divided by 2. If the remainder is 0, the number is even; otherwise it is odd.

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter an Integer
9

ODD
```
