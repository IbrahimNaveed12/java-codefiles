# Discount Checker

## Problem Title & Summary
Check a purchase amount and membership type to decide whether a discount should be applied.

## Logic & Approach
The program reads the purchase total and tests whether it is at least 10,000. If it is, it asks for membership information and uses a nested conditional to print either a 20% or 10% discount. Otherwise, it prints "No Discount".

## Time & Space Complexity
Time Complexity: O(1)
Space Complexity: O(1)

## Example Input & Output
```text
Enter your purchase amount :
15000
Enter 1 for premimum membership & 0 for regular :
1

20% Discount
```
